# SmartStock Enterprise 📦🚀

An AI-powered Smart Inventory & Demand Forecasting Management System built with Python, Streamlit, and Machine Learning.

## 🌟 Key Features
- **Real-time Inventory Tracking**: Monitor stock levels and batch information efficiently.
- **AI Demand Forecasting**: Predict future inventory needs using trained Machine Learning models (`inventory_forecasting_model.pkl`).
- **Interactive Dashboard**: Clean user interface powered by Streamlit.
- **Database Integration**: Seamless connection to PostgreSQL database.

## 🛠️ Tech Stack
- **Frontend / Dashboard**: Streamlit
- **Backend / Logic**: Python, Pandas, NumPy
- **Machine Learning**: Scikit-learn
- **Database**: PostgreSQL (Neon Cloud) / SQLAlchemy
